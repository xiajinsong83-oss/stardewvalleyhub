Corn is a crop in Stardew Valley. Below is the complete growing data.

<div class="table-wrap">

| Attribute | Value |
| --- | --- |
| Season | Summer, Fall |
| Growth time | 14 days (regrows every 4 days) |
| Seed source | Pierre's (150g); JojaMart (188g) |
| Seed price | 150g |
| Base sell price | 50g |
| Harvest quantity | 1-1 |
| Approx. profit / day | -7.1g (basic quality) |
| Trellis | No |
| Giant crop possible | No |

**Artisan uses:** Juice, Pickles.

## Tips

- Plant after the last frost in summer, fall.
- Use Quality Fertilizer for higher quality harvests and more profit.
- Note that crops die when the season changes, except multi-season crops.
