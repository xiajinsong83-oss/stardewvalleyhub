高效刷怪的关键是知道每种怪物在哪刷、什么时候刷、掉什么。本攻略列出每类怪物的最佳地点、预期掉落和最快路线。

## 四大刷怪区域

| 区域 | 解锁条件 | 常见怪物 |
|---|---|---|
| **矿井**（鹈鹕镇） | 开局 | 史莱姆、虫子、蝙蝠、幽灵、骷髅、沙虫 |
| **骷髅洞穴**（沙漠） | 修巴士解锁 | 巨蟒、史莱姆、蝙蝠、恐龙、岩石魔像 |
| **火山地牢**（姜岛） | 解锁姜岛后 | 火精灵、炎头、污泥、虎史莱姆 |
| **探险者公会任务板** | 开局 | 指定怪物讨伐悬赏 |

## 史莱姆

| 史莱姆类型 | 位置 | 掉落 |
|---|---|---|
| 绿史莱姆 | 矿井 5-40 层 | 史莱姆泥、史莱姆蛋 |
| 蓝史莱姆 | 矿井 40-80 层 | 史莱姆泥 |
| 红史莱姆 | 矿井 80-120 层 | 史莱姆泥、史莱姆蛋 |
| 紫史莱姆 | 骷髅洞穴任意层 | 史莱姆泥、彩虹碎片（稀有） |
| 虎史莱姆 | 火山地牢、姜岛 | 虎史莱姆蛋、史莱姆泥 |
| 大史莱姆（事件） | 建史莱姆屋后 | 大量掉落 |

**最快刷法**：建史莱姆屋，放进 20+ 只史莱姆，每天收割一次。这是被动刷怪——不用动手。

## 蝙蝠

| 蝙蝠类型 | 位置 | 掉落 |
|---|---|---|
| 蝙蝠 | 矿井 5-30 层 | 蝙蝠翅膀 |
| 冰霜蝙蝠 | 矿井 40-80 层 | 蝙蝠翅膀 |
| 熔岩蝙蝠 | 矿井 80-120 层 | 蝙蝠翅膀、日光石英 |
| 铱蝙蝠 | 骷髅洞穴（深层稀有） | 蝙蝠翅膀、铱矿石 |

**最快刷法**：冲到矿井 80 层以上，扫荡一层。熔岩蝙蝠成群出现。

## 骷髅与幽灵

- **骷髅**：矿井 70-120 层。掉落：骨头碎片（做配方用）、考古碎片。
- **幽灵**：矿井 50-90 层。掉落：幽灵水晶（50g）、灵质。

**提示**：幽灵穿墙飘，别追进角落。用带击退的剑保持距离。

## 沙虫（Duggy）

- **位置**：矿井 40-80 层（沙地）和骷髅洞穴。
- **掉落**：石英、大地水晶。
- **打法**：从沙地里钻出来。在沙地上慢慢走，它冒头就挥刀。

## 巨蟒（骷髅洞穴）

- **位置**：骷髅洞穴任意层（越深越多）。
- **掉落**：日光核心、电池组。
- **打法**：飞的快、伤害高。用银河剑保持移动，别正面吃。

## 胡椒恐龙（恐龙）

- **位置**：骷髅洞穴，稀有。
- **掉落**：恐龙蛋黄酱（把恐龙蛋放蛋黄酱机）、恐龙蛋。
- **打法**：体型大，用击退锤子。打一下退一步。

## 岩石魔像

- **位置**：骷髅洞穴（没靠近时看起来像石堆）。
- **掉落**：石头、晶球。
- **打法**：慢但伤害高。绕圈走位，从背后挥。

## 火精灵与炎头（火山）

- **位置**：火山地牢 1-10 层以上。
- **掉落**：火焰矿、岩浆帽。
- **打法**：带水或者等它冷却。炎头死了会爆炸——保持距离。

## 推荐路线

| 目标 | 最佳路线 |
|---|---|
| 刷史莱姆（被动） | 建史莱姆屋，每天收割 |
| 蝙蝠翅膀 | 矿井 80-90 层扫荡 |
| 骨头碎片 | 矿井 70-100 层骷髅层 |
| 铱矿石 | 骷髅洞穴深层 + 咖啡 + 香辣鳗鱼 |
| 日光核心 | 骷髅洞穴巨蟒 |
| 恐龙蛋 | 骷髅洞穴运气好的深层 |

## 出发前准备

1. **食物**：香辣鳗鱼（+运气、速度）或幸运午餐。
2. **buff**：咖啡（速度）、蟹饼（运气）。
3. **装备**：银河/无尽剑、弹弓 + 爆炸弹药。
4. **传送图腾**：沙漠图腾去骷髅洞穴，农场图腾快速回家。
