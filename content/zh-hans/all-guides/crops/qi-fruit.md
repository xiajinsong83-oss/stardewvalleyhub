**Qi Fruit** 是星露谷物语中的一种 fruit 作物。A fruit imbued with the essence of Qi. Used to complete Qi's special orders.可在 **春季、夏季、秋季、冬季** 种植，是早期最稳定的收入来源之一，几乎所有农场规划都应种植。

## 一览

| 项目 | 数值 |
|---|---|
| 季节 | 春季、夏季、秋季、冬季 |
| 生长时间 | 4 天 |
| 重复结果 | 否 |
| 种子成本 | Unknown |
| 售价 | 1g |
| 最高品质 | 铱星 |
| 类别 | fruit |
| 支架 | 否 |
| 巨型作物 | 是 |
| 种植经验 | 0 |

## 如何种植

在季节初把 Qi Bean 种在翻过并浇过水的土壤里。作物需要 **4 天**成熟。每天早晨浇水（或布置洒水器），不要让生长计时暂停。

**收获策略**：这是单次收获作物——每次收获后重新播种，保持田地产出。

## 收益分析

| 指标 | 数值 |
|---|---|
| 每株净利润 | 1g |
| 每季收获次数 | ~7 |
| 每季每株大致收益 | 7g |

选择 **农业家（Tiller）** 职业后，作物售价提高 10%，每季每株收益提升到约 **7g**。按 12×8 地块规模种植，是稳定的季节收入来源。

## 技巧与搭配

- **工匠加工**：可加工为 Wine, Jelly, Dried Fruit，价值更高。
- **洒水器**：在[农场布局规划器](/zh-hans/farmlayou/)中搭配洒水器布局，从第一天起自动浇水。
- **品质**：种植技能提升和肥料会让银星/金星/铱星品质收获的售价远高于基础价 1g。
- **季末**：换季时作物枯萎——安排种植，确保最后一次收获在 28 日之前。
